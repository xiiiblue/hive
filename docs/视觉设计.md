# 视觉设计

> 更新日期：2026-11-20

首页从员工工作台的真实界面切入，接着给出员工、管理员和接入开发者的入口。读者可以先看自己要做的事，也可以继续往下查看任务怎样在蜂巢里执行。

## 首页与架构图

- 深蓝色首屏以对话和文件界面为主图，紧邻三条角色路线。真实界面使用合成示例，文字和数值用于解释操作。
- 工作场景切换分别展示周报、文件和业务面板，每个场景连到对应的操作章节。
- 顶部导航的“功能架构图”打开独立页面`/capabilities/`，图下方可按关键词和角色查找详细功能。页面直接使用产品手册的HTML原图，支持整页滚动和单页横向打印。相邻的“系统架构”用于了解平台服务、员工工作空间、模型和业务系统之间的关系。
- 视觉延续蜂巢标识与海军蓝主色。首屏采用深蓝底、浅色文字和冰蓝重点色，阅读区采用冷白和深色正文。界面使用设备已有的无衬线字体。
- 官网从产品技术手册的`官网素材/hive-logo.png`导入真实Logo。该文件与工作台的`apps/workbench/src/assets/default-logo.png`一致。页头、页脚、首页工作台展示和标签页图标共用`public/media/hive-logo.png`，深色背景上的标记使用浅色底托。分享图源也引用同一资产，更新后一起重新渲染PNG。

## 手册与文档中心

- 手册入口先让读者选择员工或管理员，再给出常做的事和完整章节。每份操作手册的示例图随产品更新重新拍摄。
- 文档中心用类别和快捷检索引导读者。宽屏正文两侧分别提供章节和本页目录，窄屏用可展开的菜单省出阅读宽度。
- 截图可以放大，表格和代码块在自己的区域内滚动。搜索、目录和图像放大均支持键盘，页面保留打印和明暗主题。

发布前检查桌面与手机上的阅读顺序、文字可读性、截图内容、首页图片资源、搜索、章节目录、图片放大和功能目录筛选。检查结果记录在对应改版记录。
