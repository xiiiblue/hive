# 视觉设计

> 更新日期：2026-11-20

官网以深蓝和冷白为主。浅底页面的主要按钮和选中场景使用深蓝，链接用灰蓝和下划线标示。首页从员工工作台的真实界面切入，接着给出员工、管理员和接入开发者的入口。

## 首页与架构图

- 首页按普通页面滚动。首屏的工作台、文件管理和业务面板截图水平摆放。两侧预览位于深色区内，只压暗截图本身，外框颜色稳定。手机只显示当前主图。轮播进入视野时自动播放，移出视野时暂停。读者可以暂停或选图，也可以点击主图放大。开启减少动态效果时，默认停在第一张。
- 在周报、文件和业务面板三个工作场景间，用按钮或键盘左右切换时，新截图从对应方向轻滑进入。截图外框、操作步骤区域和后续内容位置保持稳定。开启减少动态效果时直接切换。
- 顶部导航的“功能”打开独立页面`/capabilities/`，图下方可按关键词和角色查找详细功能。页面直接使用产品手册的HTML原图，底色、标题、内容边距和按钮沿用官网样式，支持整页滚动和单页横向打印。相邻的“架构”用于了解平台服务、员工工作空间、模型和业务系统之间的关系。系统架构图和员工数字分身概念图共用深蓝标题带。
- 官网从产品技术手册的`官网素材/hive-logo.png`导入真实Logo。该文件与工作台的`apps/workbench/src/assets/default-logo.png`一致。页头、页脚和标签页图标使用`public/media/hive-logo.png`。首屏截图使用产品界面自身的标识。分享图源也引用同一资产，更新后一起重新渲染PNG。

## 手册与文档中心

- 手册入口先让读者选择员工或管理员，再给出常做的事和完整章节。每份操作手册的示例图随产品更新重新拍摄。
- 文档中心用类别和快捷检索引导读者。宽屏正文两侧分别提供章节和本页目录，窄屏用可展开的菜单省出阅读宽度。
- 截图可以放大，表格和代码块在自己的区域内滚动。搜索、目录和图像放大均支持键盘，文档可以打印。

发布前检查桌面与手机上的阅读顺序、文字可读性、截图内容、首页图片资源、搜索、章节目录、图片放大和功能目录筛选。检查结果记录在对应改版记录。
