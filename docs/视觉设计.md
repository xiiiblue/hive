# 视觉设计

> 更新日期：2026-11-24

官网采用极简纯白与精密中性灰设计体系，与蜂巢工作台（Workbench）及HiveBridge桌面工具一脉相承：以纯白（`#ffffff`）与极浅灰（`#fafafa`）为画布，碳黑（`#111113` / `#18181b`）为主文字与主按钮锚点，辅以极克制的电光蓝（`#2563eb`）作为状态圆点、微光晕与核心高亮，通过精密网格线、1px细线分割与玻璃质感卡片营造现代软件产品的设计感。

## 首页与架构图

- 顶部导航采用毛玻璃胶囊分组，当前栏目以纯白浮起标签高亮，右侧提供快捷文档搜索（`⌘ K`）；窄屏自动切换为抽屉导航。
- 首页采用非对称左文右景首屏：背景铺设极淡建筑细网格与右上微光晕，左侧呈现核心价值主张、操作入口与3项平台指标，右侧以三层向右上错位叠放的纯白玻璃窗口展示真实工作台、文件管理与业务面板界面，支持自动轮播、手动切换与点击灯箱放大（开启减少动态效果时停在首图）。
- 首屏下方采用3列非对称Bento网格展示工作空间、Skill沉淀、多渠道机器人、定时自动化、可视化业务面板与碳黑短期身份信任链，随后以三步虚线连接流程、可左右滑入切换的真实界面演示、连续工作图、三角色入口卡片与通透纯白行动区收束全页。
- 顶部导航的“功能”打开独立页面`/capabilities/`，直接使用产品手册的HTML原图并映射全站纯白、碳黑与电光蓝变量，支持按关键词和角色筛选62项功能，支持整页滚动与单页横向打印。“架构”与“产品”页嵌入的手册原图同样统一为极简黑白灰与电光蓝体系，单独打开原图文件时保持原浅底配色。
- 官网从产品技术手册的`官网素材/hive-logo.png`导入真实Logo，页头、页脚和标签页图标使用`public/media/hive-logo.png`。

## 手册与文档中心

- 手册入口以双栏大卡片展示员工工作台与管理员控制台，包含10章编号索引与高清界面预览。
- 文档中心提供带篇数统计的主题胶囊导航与双列文档卡片。宽屏正文两侧分别固定章节树和本页目录，顶部显示碳黑至电光蓝渐变阅读进度条；窄屏使用紧凑折叠菜单省出阅读宽度。
- 截图支持适屏与原始尺寸灯箱放大，表格和碳黑代码块在各自区域内横向滚动。全文搜索、目录定位和图片放大均支持键盘操作，正文支持干净打印。

发布前检查桌面与手机上的阅读顺序、文字对比度、截图内容、首页图片资源、全文搜索、章节目录、图片放大和功能目录筛选。检查结果记录在对应改版记录。
