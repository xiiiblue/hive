## 更新操作

1. 在hive-os完成正文和配图的产品事实核对，确认图片仍使用真实Vue页面与隔离合成数据。
2. 在本网站根目录运行`node scripts/import-manuals.mjs`。脚本只读`../../telchina/hive-os`，覆盖本网站的已生成内容和配图，不调用业务接口。
3. 检查`content/employee/`、`content/admin/`和`public/media/manuals/`的差异。正文修订应回到来源手册；生成文件中的手工修改会在再次导入时覆盖。
4. 运行`npm run check`，并在浏览器核对桌面与手机阅读、搜索、目录、跨章链接、图片放大及暗色主题。导入脚本的成功不能代替这些站点检查。
5. 由负责人按本仓库发布流程处理提交和上线，保留检查结果。

## 路由和内容处理

- 各章的英文slug在导入脚本中明确指定。修改中文标题或源文件名时，保留原slug；不要根据标题自动重建公开URL。
- `content/article-mapping.json`的键为hive-os仓库相对来源路径，值为`/docs/{employee|admin}/{slug}/`，不带网站基础路径`/hive`。README映射到对应的`overview/`。
- frontmatter保存标题、摘要、所属手册、顺序、更新日期和来源路径。正文移除原一级标题、顶部治理元数据、内部源码核对依据和旧版前后章页脚，由网站统一提供导航。
- 已知章节Markdown链接按完整来源映射改写，未知内部链接只保留可读标签，不生成通往私有源码或内部文档的地址。图片改写为`/media/manuals/{employee|admin}/文件名`；网站渲染时统一补`/hive`。不递归复制链接目标。
- overview保留用途、十章目录、阅读建议、图片说明和适用边界，删除原离线HTML操作、内部维护步骤及内部文档入口。

## 网站检查命令

在网站根目录运行`npm run check`，依次执行Astro类型检查、静态构建和`node --test tests/site.test.mjs`。静态测试读取本次构建的`dist/`，不会访问业务接口，也不需要增加测试依赖。若已经完成构建，可以单独运行最后一个命令排查失败。

测试按实际Markdown数量检查搜索索引与文档页面，本期要求至少42篇。搜索内容须包含完整正文和代码示例，不能只收录摘要。测试还核对首页与主入口、所有HTML中的站内链接和图片、片段目标、HTTPS规范URL、文档标题，以及同一分区的前后章节顺序。

公开HTML、JSON和SVG会检查本机用户路径、内网及回环IPv4、常见可用凭据格式和私有hive-os源码链接。压缩JavaScript和二进制图片不做数字匹配，避免把程序数字误判为地址；图片仍需人工复核。教学用example.invalid地址保留。发现疑似敏感内容时，测试只报告文件及问题类别，不将匹配内容输出到日志。

这套测试验证构建产物的内容和链接；桌面、手机、搜索交互、主题切换、目录与图片放大仍按上面的更新步骤在浏览器检查。

## 产品、架构和开发正文

content/product、architecture、developers和insights为面向公开读者重新组织的20篇正文，并非内部设计镜像。各篇frontmatter的sources记录实际依据；改写后同时核对当前设计和实现，不能从交流稿单独推导产品承诺。新增文章只需保持稳定文件名并填写元数据，目录、搜索与前后篇导航在构建时自动更新。

开发例子使用example.invalid，凭据从运行时安全配置取得，不打印完整系统上下文、Token或真实账号。新资料应先完成公开化整理；不能把内部目录加入自动递归发布列表。

## 浏览器复核与分享图

先运行npm run check，再运行npm run preview -- --port 4328。设置HIVE_SITE_PLAYWRIGHT为本机已有Playwright的index.mjs绝对路径、HIVE_SITE_CHROME为Chrome可执行文件绝对路径，然后执行npm run check:browser。工具不下载浏览器，不读取业务凭据；默认检查本机静态预览，可用HIVE_SITE_PREVIEW选择其它站点来源。

工具检查场景与架构标签切换、全文搜索/空结果/快捷键、图片放大、章节定位、打印、390px阅读、320/768/1024px首页布局、手机导航以及明暗偏好保存，截图与结果写入忽略的.verification/。public/media/social-cover.svg是分享图源文件；浏览器复核的最后一步将其渲染为同目录PNG，供分享元数据使用。分享图改变后重新构建，使新PNG进入dist/。

机器检查不评价审美；仍要查看首页、架构、手册和长文的桌面及手机截图。图片可在各自区域内放大或横向滚动，不允许整页横向溢出。
