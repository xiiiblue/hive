# 建设与上线记录

## 2026-10-16：首期网站

网站与蜂巢产品源码并列建立，目标为`https://www.bluexiii.com/hive/`。产品仓库只读，博客和ACDL仓库只读；网站使用独立GitHub项目仓库及Pages工作流。

### 实际建设

- 7类主页面：主页、产品、架构、操作手册、开发对接、文档中心、交流与实践；另有42篇正文和404页面，共50页。
- 两类操作手册22篇，继承已复核的131张合成数据界面截图与2张概念图。
- 新写产品4篇、架构5篇、开发8篇、交流3篇；保留当前权限、网络、业务回滚和生产适用边界。
- 支持完整正文及代码搜索、快捷键、结果键盘选择、目录与章节导航、图片放大、打印、明暗主题和手机布局。
- 使用Astro7.4.0和Node24.18.0，依赖精确锁定，构建不读取同级私有产品仓库。

### 内容与图示复核

产品和架构文章、开发指南由未参与对应正文撰写的代理交叉只读复核，对照当前Accepted设计与实现。模型访问码、业务Token、OIDC、同步与异步取消、面板身份、MCP契约和单节点范围未发现未处理的实质偏差。架构图曾误画平台存储到员工运行环境的箭头，已删除。

两册导入保留正文和原图，移除治理元数据、维护章、源码依据和私有目标链接。旧MCP动态注册方案、旧六类连接方式、含真实测试凭据的开放API材料及内部联调记录均未直接发布。面板例子只展示业务结果，不输出完整系统上下文或Token。

### 验证与修正记录

初次类型检查发现Markdown渲染器属性类型问题，已显式转换为字符串；静态测试发现开发正文重复一级标题，已由渲染器去除正文开头标题；404特殊页面的物理路径与规范URL已按Astro输出处理，测试同步修正文件到URL映射，没有跳过其它链接。

浏览器检查发现搜索输入框原生Esc行为会先清空输入，已显式关闭搜索窗口。桌面、手机、全文搜索与无结果、键盘切换、图片放大、目录定位、打印和主题保存已通过，原图及结果保留在本地验证目录。

默认npm镜像不支持审计接口，改用官方npm源。首次审计发现gray-matter旧依赖链的4项中等风险，移除该依赖，改用当前YAML解析器；最终审计结果、静态检查、提交和上线信息在完成后追加。

### 首页与视觉改版

首版未发布，用户指出旧配色与过简的首页不符合期待。阅读Anthropic的frontend-design指导后，重新采用海军蓝、钴蓝和冷白色，重做首页构图、品牌标记、产品概念图、分享图以及通用阅读配色。首页以真实工作台局部、成果文件和个人Skill形成主视觉，接着展示可切换场景、持久空间、身份与授权、架构、两册手册和开发入口；不增加虚构客户或效率数据。具体约定见[视觉设计](视觉设计.md)。

独立截图复核确认桌面、手机和暗色模式的主要构图未见碰撞或截断；同时纠正首页一处Skill文案：技能广场用于选择当前可用技能，安装入口在技能市场。操作手册原图保持原样，网站配色调整不改变产品截图。

最终类型检查为0错误、0警告、0提示，构建50页，6组静态测试全部通过且无跳过。生产依赖审计为0项漏洞。浏览器检查通过场景及架构标签切换、键盘操作、完整正文与代码搜索、空结果、图片放大、目录定位、打印、手机导航和主题保存；另检查320、390、768、1024、1440px首页。平板工具图与段落相互靠近，已缩小示意图并重新逐档截图核对。
